My Game Development Projects

My First 3D Game

I developed a project for the 3D Game Design and Development course at Saint Francis University, Bunny's Hunny Hop marks my first venture into 3D game creation using the Unity engine and C#. The project is a fast-paced, endless runner that challenges players to maximize their score by collecting scattered items while navigating a rapidly accelerating environment. Leveraging Unity's free asset library, I styled and constructed a vibrant, immersive 3D world that dynamically tests player reflexes. To keep the gameplay engaging, the game features a progressive difficulty loop where the movement speed continually increases, demanding precise timing to dodge sudden obstacles like rocks. .

Mission Unbreakable

I developed a project for the 3D Game Design and Development course at Saint Francis University, The Mission Unbreakable is an objective-based puzzle platformer built using the Unity engine and C#. The game utilizes a structured, level-based progression system where players must successfully complete unique, escalating missions to advance and ultimately win. Key gameplay mechanics include color-matching box puzzles, an exploration-driven coin collection system, traditional physics-based platforming, and a dynamic "Giant Ghost" boss encounter. While the current prototype is fully functional and successfully demonstrates core component-driven architecture and asset integration, it remains an iterative project with planned future enhancements focused on tightening player movement controls, expanding the boss AI, and adding polished visual effects.

Final Year Project

I developed a collaborative Final Year Project, Fall of Biotech is an immersive, narrative-driven Role-Playing Game (RPG) built using the Unity engine and C#. The project successfully established a cross-software pipeline, seamlessly importing and optimizing custom 3D character models and environmental assets created in Autodesk Maya. To elevate the game's world-building, our group integrated advanced AI tools to assist in structuring the overarching storyline, refining dialogue branches, and developing deep lore. The core gameplay loop centers on an objective-driven mission where players must explore environments to collect critical evidence, culminating in a highly scripted final boss encounter featuring dynamic enemy and health-tracking systems.
